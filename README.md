# Screenshot Toggler App

React Native app to toggle screenshot capture ON/OFF using native code.

## Features
- Native plugin (Android/iOS) to disable screenshots
- Redux for state management
- Alerts on screenshot capture
- Device info + API POST

## Tech
- React Native (CLI)
- Redux Toolkit
- Native Modules
- TypeScript

## Install & Run

git clone https://github.com/your-username/screenshot-toggler-app
cd screenshot-toggler-app
npm install
npx pod-install
npx react-native run-android # or run-ios
